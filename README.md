# Kodree - Data Analyst Career Path 📊

¡Bienvenido a mi repositorio de ejercicios y proyectos diarios! Aquí documento mi evolución y práctica constante a lo largo del **Data Analyst Career Path** en [Kodree](https://kodree.com).

El propósito de este espacio es almacenar el código, las consultas y los análisis desarrollados durante mi formación técnica en el análisis de datos.

---

## 🛠️ Tecnologías y Herramientas

Las prácticas y retos diarios se centran en el dominio de Python aplicado al análisis de datos y las herramientas esenciales de la industria:

* **Python & Python for Data Analysis:** 
  * **Python Core:** Estructuras de datos, funciones, manejo de excepciones y buenas prácticas de programación.
  * **Librerías Clave:** Manejo avanzado de **Pandas** para transformación de DataFrames, **NumPy** para operaciones numéricas eficientes, y **Matplotlib / Seaborn** para visualización exploratoria.
* **SQL:** Consultas avanzadas, uniones, agregaciones y extracción de datos desde bases de datos relacionales.
* **Excel:** Modelado de datos, tablas dinámicas y análisis operativo.
